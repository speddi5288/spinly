# Sample recipe photography

Created with the built-in image generation tool for the Step 2 sample collection. These images illustrate sample flavors and do not document tested recipes.

All six WebP files are stored in `public/recipes/` and served locally. The generated originals were encoded as WebP at quality 82 without cropping or resizing (1254 × 1254 pixels). The six web assets total about 850 KB. The UI uses lazy loading and an accessible fallback if an image cannot load.

## Final prompts and saved assets

### vanilla

[vanilla.webp](../public/recipes/vanilla.webp)

Use case: photorealistic-natural. Asset type: one square recipe card photo for a homemade Ninja CREAMi ice cream app. Create one 1024x1024 photorealistic editorial food photograph. Three beautifully textured scoops of vanilla bean ice cream, visible tiny vanilla seeds, in an unbranded pale cream ceramic bowl. Vanilla pods beside the bowl on a warm light sand tabletop.
